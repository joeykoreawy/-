# 작지의나라

첨부 한지풍 디자인을 바탕으로 구현한 Django 웹사이트입니다. 글·회원·제안·신고는 **서버의 공용 SQLite 데이터베이스**에 저장됩니다. 다른 브라우저에서도 같은 데이터를 보며, 브라우저 저장소에 의존하지 않습니다. PythonAnywhere 무료 단일 웹앱으로 소규모 운영을 시작하는 구성입니다.

## 구현 범위

- 회원가입·로그인·로그아웃·비밀번호 변경, 회원별 비공개 연락처 관리
- 한 회원의 의뢰인·기사 역할 동시 사용
- 태초만 운영, 옛날바람·클래식바람·구바람의나라 준비 중 (서버에서도 등록 차단)
- 비로그인 공개 게시판·상세·검색·직업/진행 상태 필터·페이지 나누기
- 본인 의뢰 등록·수정·삭제, 기사 제안 등록·수정·철회
- 의뢰인의 기사 선택, 매칭 당사자만 연락처 확인
- 선택된 기사의 작업 시작 → 의뢰인의 완료 확인, 당사자의 취소
- 신고 접수·본인 처리 결과 조회, 운영자의 신고 처리·의뢰 숨김/복원
- 서버 세션·CSRF·비밀번호 해시·접근 권한·로그인 시도 제한·감사 기록
- 결제와 실시간 채팅, 게임 비밀번호·OTP 수집은 포함하지 않음

## 로컬/클라우드 개발 실행

Python 3.12 권장 (Django 5.2 지원 버전 사용). 기존 체크아웃을 사용하며 새 Git worktree를 만들 필요가 없습니다.

```bash
bash scripts/setup.sh
bash scripts/start.sh
```

`setup.sh`는 고정 버전 의존성 설치, 비밀키 최초 생성, DB 마이그레이션, 정적 파일 수집을 수행합니다. 반복 실행해도 기존 비밀키와 DB를 보존합니다. 비밀키·설정·DB는 Git에서 제외된 `.local/`에 저장됩니다. 로컬 실행은 HTTP와 루프백 호스트만 허용하며, 공개 배포는 별도 HTTPS 설정이 필수입니다.

서버 준비 여부는 `/health/`의 HTTP 200과 `ok` 응답으로 확인합니다. 운영자는 다음 명령으로 직접 생성합니다. 기본 관리자나 공개 비밀번호는 없습니다.

```bash
.venv/bin/python manage.py createsuperuser
```

운영자도 일반 로그인 후 **내 활동 → 운영자 신고 관리**를 이용합니다. 일반 회원에게는 관리 메뉴와 처리 권한이 없습니다. `/admin/`에는 사용자/권한 관리와 읽기 전용 감사 기록만 노출하며 연락처·제안의 일괄 조회 메뉴는 제공하지 않습니다.

## 검증

```bash
.venv/bin/python manage.py test --verbosity 1
.venv/bin/python manage.py makemigrations --check --dry-run
```

브라우저 검증은 **별도 테스트 DB**에서 수행합니다. 실제 사용자 DB나 공개 사이트를 대상으로 실행하지 마세요.

```bash
DJANGO_DATA_DIR="$PWD/.local/e2e" .venv/bin/python manage.py migrate --noinput
DJANGO_DATA_DIR="$PWD/.local/e2e" BIND=127.0.0.1:8001 bash scripts/start.sh
```

다른 터미널에서 Playwright와 Chromium이 설치된 Python으로:

```bash
python scripts/browser_smoke.py
```

현재 스크립트는 `/usr/bin/chromium`을 사용합니다. 결과 JSON과 화면 캡처는 `artifacts/`에 저장되며 합성 테스트 계정과 연락처만 사용합니다. 서비스 DB와 배포 압축파일에 이 데이터는 포함하지 않습니다.

## 상태와 권한

| 작업 | 권한 / 조건 |
|---|---|
| 글 읽기 | 누구나, 운영자 숨김 글 제외 |
| 글 수정 | 의뢰인 본인, 제안 모집 중만. 수정 후 기존 제안은 재확인 필요 |
| 글 삭제 | 의뢰인 본인, 모집 중/취소만. 제안도 삭제, 신고 사본은 유지 |
| 제안 | 로그인한 타 회원, 본인 연락처 등록, 모집 중 의뢰 |
| 제안 조건 보기 | 의뢰인과 해당 제안자 본인 |
| 기사 선택 | 의뢰인 본인, 최신 조건의 제안, 양측 연락처 등록 |
| 연락처 보기 | 매칭/진행/완료 상태의 당사자만. 취소/숨김 시 중단 |
| 작업 시작 | 선택된 기사만, 매칭 상태에서 |
| 완료 확인 | 의뢰인만, 진행 중 상태에서 |
| 취소 | 모집 중 의뢰인 또는 매칭/진행 중 당사자 |
| 신고 처리 | 활성화된 `is_staff` 운영자만 |

기사 선택·제안 저장·조건 수정·상태 변경은 DB 트랜잭션으로 보호합니다. SQLite의 IMMEDIATE 트랜잭션으로 동시 기사 선택을 직렬화합니다. 한 기사당 한 의뢰에 한 제안만 존재할 수 있으며 금액은 DB에서도 범위를 제한합니다. HTML은 기본 이스케이프, 개인정보 포함 페이지는 `no-store` 캐시 정책을 사용합니다.
